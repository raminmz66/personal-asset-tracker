# Money-only UI mockups

Static HTML previews for the Calm notebook PWA (Persian RTL). Open in a browser.

| File | What it shows |
|---|---|
| `person-balances.html` | Person screen — موجودی‌ها only (+ افزودن موجودی, تسویه‌شده‌ها) |
| `balance-history.html` | Balance screen — amount + واریز/برگشت + تاریخچه |
| `home-people.html` | Home — people list + status (no tools) |

Visual tokens: page `#F4EFE6`, ink `#3D3428`, accent `#0F6B6B`.
